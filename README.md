## How I approach a build

- Start with the decision or business process the tool should improve.
- Keep observed data, estimates, demo fixtures, and proposed changes distinguishable.
- Build clear failure states and a repeatable way to check the result.
- Connect activity to accepted inquiries, bookings, or another defined outcome before claiming impact.

**Tools:** Python · TypeScript · React · FastAPI · SQLite · APIs · GitHub Actions
